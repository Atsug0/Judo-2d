# Fiches personnages (style jeu de combat, cel-shading)

Générées par Hugo (ChatGPT) à partir du prompt « feuille de personnage ».
Chaque dossier contient la fiche complète et ses quatre vues découpées, à la même échelle :

| Dossier | Judoka |
| --- | --- |
| `homme_blanc/` | homme, judogi blanc (tori par défaut) |
| `homme_bleu/` | homme, judogi bleu |
| `femme_bleu/` | femme, judogi bleu |
| `femme_blanche/` | femme, judogi blanc |

Fichiers : `fiche.png` (les quatre vues), `face.png`, `profil.png`, `dos.png`, `trois_quarts.png`,
et `pose_t.png` (vue de face bras écartés, fond blanc) pour la génération de modèles 3D.
La vue `profil.png` sert de base aux sprites du jeu (le combat est vu de côté).
